# 小布键盘助手

> OPPO / 一加 ColorOS 小布输入法的 LSPosed 模块：自定义 26 键上滑字母 / 符号、调整左下角功能键位置，并可替换键帽上滑字符的颜色。

## 功能

- **逐键自定义上滑符号**：点按键帽即可设置该键的上滑符号，留空恢复默认，也可单独禁用某一键的上滑
- **中英文独立映射**：中文 26 键（拼音 / 五笔）与英文 26 键分别配置，互不影响
- **上滑字符颜色**：键帽右上角的上滑符号可换成自定义颜色，**白天 / 黑夜各一套**，跟随输入法主题自动切换，切换系统深浅色无需重启输入法
- **左下角功能键换位**：主键盘「符号 ⇄ 123」、符号面板「返回 ⇄ 123」、数字面板「符号 ⇄ 返回」；主键盘与面板各有一个独立子开关，只交换功能与样式，键位尺寸保持原样
- **隐藏剪切板设置键（可开关）**：剪切板 / 常用语页顶栏最右侧的设置齿轮不再显示，编辑键保留
- **一键恢复 / 清空**：恢复默认映射或清空全部按键
- **配置导入导出**：配置以 JSON 文件导出 / 导入，兼容旧版本配置，换机无忧
- **保存即时生效**：保存后输入法自动重启并应用新配置

## 兼容性

适配小布输入法 **1.9.18.17 → 1.9.25.17**，跨版本不断代：

| 功能 | 跨版本处理方式 |
|---|---|
| 左下角功能键换位 | 按方法签名定位布局工厂（新旧版本方法名不同也能命中），并直接改写布局对象，不依赖混淆名 |
| 上滑符号映射 | 遍历宿主全部静态映射表，按内容识别字母布局，新版新增的语言表也能覆盖 |
| 上滑字符颜色 | 挂在主题属性读取点，新旧版本共用同一条链路 |
| 日夜判定 | 复用宿主自身的日夜模式解析，兼容「跟随系统 / 强制夜间」 |

宿主的混淆名、布局数量发生变化时不会硬编码，找不到目标类只会静默跳过，不会影响输入法本身。

## 使用要求

- 已获取 Root，安装 [LSPosed](https://github.com/LSPosed/LSPosed) 2.2 及以上（或支持 libxposed API 102 的框架）
- 在框架中启用本模块，作用域勾选「小布输入法」

## 安装与使用

1. 从 [Releases](../../releases) 下载 APK 安装
2. 在 LSPosed 中启用模块，作用域选择小布输入法（`com.oplus.keyboard`）
3. 打开模块，进入「中文26键 / 英文26键」设置各个键的上滑符号
4. 需要换位或改角标颜色时，到「模块与数据 → 功能开关」打开对应开关
5. 点击底部「保存并应用配置」，输入法自动重启生效

> 改动模块或更新模块版本后，建议手动结束一次输入法进程（或在 LSPosed 中重启作用域应用），确保新模块被加载。

## 构建

```bash
./gradlew assembleDebug
```

产物位于 `app/build/outputs/apk/debug/`。仓库自带 GitHub Actions 构建（Actions → Build Debug APK → Run workflow），可在触发时自定义版本号与安装包名称。
